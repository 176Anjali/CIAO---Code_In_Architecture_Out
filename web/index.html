Keep documentation in sync with GitHub

Add a GitHub Actions workflow to a repository. Each push will create or update its documentation and architecture diagram, then commit the files back.

Download GitHub sync setup
  1. Extract the ZIP directly into your repository root, keeping the folders shown.
  2. Commit and push those files. The workflow runs on that first push and on later pushes.
  3. Open the repository’s Actions tab to follow progress. Generated files appear in docs/.

Ollama is the default. GitHub-hosted runners install Ollama and download llama3.2:3b when the workflow runs. For faster repeat runs, use a self-hosted runner with Ollama already installed. The setup guide also explains how to select OpenAI or another compatible API.

Ollama note: an Ollama server running only on your laptop cannot be reached by GitHub-hosted runners. Use Ollama on the runner, a self-hosted runner, or a reachable Ollama API URL.
